# Plinth US Grants Data

A JSON API over the entire US grantmaking universe (~205,000 funders and 17.9M grants) read from public IRS Form 990/990-PF e-file data and the IRS Business Master File. Offers REST endpoints for grants, organizations, search, an ad-hoc SQL endpoint, and a hosted MCP connector for AI agents.
